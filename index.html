关于我

我在香港大学读博，研究游戏中的智能角色。此前，我在米哈游参与了内部大模型预训练、《崩坏：星穹铁道》相关的 NPC 问答后训练，以及《星布谷地》多人交互角色娜洛的研发。

做娜洛时，我常碰到这样一个问题：几位玩家围在一起聊天，角色怎么知道哪句话是对自己说的？我也关心角色该记住哪些线索，以及玩家离开一段时间后，它能否推断世界里发生了什么变化。

研究构想

潮汐湿地

玩家开闸后离开，回来时原先的小路已经被水淹没。要判断接下来能走哪条路，角色需要分清水位变化有多少来自潮汐，有多少来自刚才的开闸。这个虚构湿地也为观察栖息地和动物活动的变化提供了环境。

研究构想

维修站

玩家伸手接过角色递来的零件：两只手何时接触，物品何时换了持有者，任务又该何时显示完成？我想用一次交接研究角色动作与游戏状态如何对齐。

在写论文

我担任以下三篇稿件的唯一第一作者，目前均在撰写中。

  1. Counterfactual Post-Training for Multiplayer Game NPCs

    只改变请求的对象或物品归属，比较两段近乎相同的对话。研究如何通过后训练让 NPC 相应调整倾听、澄清或执行的决定。

  2. Action-Conditioned World Models for Persistent Game Ecosystems

    研究在局部可观测的游戏生态中，如何区分环境自身的演变与玩家行动的后果，并预测哪些路线和资源仍然可用。

  3. Task-Conditioned Visual Memory for Game Agents under Fixed Token Budgets

    在相同的视觉 token 预算下，研究智能体能否按任务挑选历史画面，在返程找路或回头取物时保留各自需要的线索。
