《星布谷地》娜洛 · 多人 NPC 研发

多人 NPC 的记忆、发言决策与工具执行

多人会话中，发言者、受话者与动作授权人可能是三个不同的人。玩家可以在工具返回前修改请求。此时即使正确识别了意图，沿用过期参数或重试一次已经生效的操作，仍然会改变错误的游戏状态。

决策边界
先判断本轮是否需要角色介入，再判断已有证据是否足以执行。对象不明时追问，对象明确但工具状态未知时查询原请求。
评估设计
固定同一段历史，只替换授权人、被引用的委托版本或工具回执。记录成对样本能否同时判对，并分别统计错误执行、重复提交与有效委托完成率。始终等待的策略也会因漏办受罚。

我担任以下三篇稿件的第一作者（无并列一作），目前均在撰写中。

  1. Counterfactual Post-Training for Multiplayer Game NPCs

    在相同训练样本预算下，比较普通指令微调与反事实偏好训练。关键检验是：只改变受话者或物品归属，策略能否同时解出成对场景，并维持有效任务完成率。

  2. Action-Conditioned World Models for Persistent Game Ecosystems

    研究在局部可观测的游戏生态中，如何区分环境自身的演变与玩家行动的后果，并预测哪些路线和资源仍然可用。

  3. Task-Conditioned Visual Memory for Game Agents under Fixed Token Budgets

    固定视觉 token 预算与观测轨迹，只切换下游目标。比较近期帧保留、视角检索与任务条件检索对行动成功率和推理延迟的影响。

研究构想与实验设计

研究构想 · 行动条件世界模型

部分可观测生态中的行动后果预测

潮汐湿地提供了一个可控的状态估计问题。相同水位可能来自外部潮汐，也可能来自玩家开闸后的持续补水。两者在当前视角下难以区分，却对下一次通行窗口有不同预测。

研究假设：显式保留干预历史，有助于智能体在未见过的河道布局中判断何时通行、何时应付出代价补充观测。

查看实验设计与评价指标
成对推演
拟搭建一个可重复运行的湿地模拟器。从同一初始水位、潮相和地形出发，只改变一次开闸操作，再用相同的潮汐序列推演两条轨迹。另选当前水位相近、来水历史不同的时刻，检验模型能否预测下一次可通行窗口。
生态约束
设定虚拟水鸟在浅滩连续露出一段时间后才开始觅食。巡护任务既要按时到达对岸，也要避开觅食中的鸟群。水位决定何时能走，浅滩此前暴露了多久则影响哪条路适合走。
部分可观测
角色只能看到沿途画面、自己的操作和最后一次闸位读数。拟比较只看当前画面、保留观察历史、同时建模玩家操作三种方法。若队友可能在离屏期间改闸，可选择先去查看闸位，并计入额外路程。
怎样判分
用模拟器的完整轨迹核对预计通行时刻和开闸造成的水位差，再比较限时抵达率、穿越觅食区的次数与观测成本。测试时更换河道布局和潮汐周期。

研究构想 · 可中断角色动画与交互控制

指令中断下的角色动作重规划与归属一致性

维修站以多人零件交接为实验任务。接收者中途变更时，相同指令落在接触前、共持期或释放后，对应三组不同的可行动作。难点在于连续的物理接触和离散的背包归属可能在不同帧更新。

研究假设：以实际抓取状态触发重规划，能在控制响应延迟的同时降低掉件和错误结算率。

查看实验设计与评价指标
动作与任务
拟让上层策略选择继续递交、暂停、收回或转交，下层控制器在每个仿真步跟踪手腕、抓取点与物体姿态。任务记录同时保留预期接收者与实际持有者，接到改口时先更新目标。
交接边界
双方共持时，原持有者可以暂停释放，等对方松手后再收回。原持有者已经释放且甲抓稳时，归属转到甲。任务只有在当前指定的接收者抓稳后才结算一次。
成对试验
固定角色站位、零件、动作起点和改口录音，只把指令移到释放前后不同的仿真帧。再分别加入手部遮挡、乙伸手较慢两种扰动，比较播完整段动画、按固定关键帧切换和根据接触状态重新规划三种控制方式。
怎样判分
分别记录改口到动作调整的延迟、共持阶段的手物滑移距离、掉件率、错误归属与重复结算次数。即使画面衔接自然，只要背包中的零件记到了错误玩家名下，这次交接就算失败。
